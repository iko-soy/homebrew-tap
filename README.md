# homebrew-tap

Homebrew tap for ilyakooo0 packages.

## Usage

```
brew tap ilyakooo0/tap
```

### Parseable Viewer

A macOS client for [Parseable](https://github.com/ilyakooo0/parseable-macos).

```
brew install --cask parseable-viewer
```

### Diagonal

A Brave extension that groups and names tabs with Apple's on-device model ([iko-soy/diagonal](https://github.com/iko-soy/diagonal)).

```
brew install iko-soy/tap/diagonal
```

Then run `sudo fm license` once to accept Apple's terms for `fm`, and load `~/Library/Application Support/Diagonal/extension` at `brave://extensions` (Developer mode → Load unpacked). The cask's caveats walk through it.

### SourceDocsSwift

```
brew install sourcedocsswift
```
